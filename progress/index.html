Decompiler noise

Placeholder variables (in_, unaff_, extraout_) the decompiler invents when it lacks information. Each fix to the processor model or calling convention brings this down. Inputs from the FPU's back register bank (in_xf, in_xd) are not counted: that bank is the hardware matrix (XMTRX) one routine loads and later code reads, so those are real inputs.
